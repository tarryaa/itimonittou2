## 軽量化とテーマ追加

v1.2.0では、全文データを保持しつつ画面周辺だけを描画し、スクロール時の保存を位置とセッション進捗に限定します。初期描画6問、比較テストのスクロール中最大13問。問題IDと相対位置を使う復元、長い編集問題の1000px途中からの再開、画面幅390→740→390変更時の位置保持、独立補足33/45ページ、絞り込み近傍移動を両ブラウザで確認しました。既存DBのバージョン・ストアを変更せず、旧版の緊急保存データにも対応します。

[性能比較](PERFORMANCE.md)は同一条件3回の中央値で、初期表示7.25秒→1.16秒、DOM53,722→365、一括非表示2.12秒→約0.047秒。実機iPhoneの数値ではありません。

設定で「栞（オリジナル）」「アクア・ダーク」「アクア・ライト」の3テーマを選べます。元の配色を完全に戻せること、新テーマが描画数を増やさないこと、テーマ・文字サイズ・間違い履歴・深い位置を即時再起動後も維持すること、旧バックアップは元テーマになり、不正なテーマを拒否することを検証しました。起動時の配色ヒントは小さなlocalStorage値ですが、選択の原本は従来どおりIndexedDBです。

公開サイトでもChromium/WebKitで3テーマを切替→再読み込みし、選択・間違い記録の保持、赤字の透明マスク、横はみ出しなし、描画40問以下、メタカラー切替を確認しました。[実測JSON](LIVE_THEMES.json)、[ダーク](theme-aqua-dark.png)、[ライト](theme-aqua-light.png)、[設定画面](theme-picker.png)を保存しています。公開サイトの基本検証では両エンジンとも6問だけを描画し、全1,496問は利用可能です。

## 未検証・元データの制限

- iPhone実機Safari、実機ホーム画面追加・アイコン起動、実機完全終了後の再起動。Playwright WebKitは実機Safariそのものではない。
- 公開サイトの旧版を保持した同一ブラウザで、更新通知から新版へ切り替える操作そのもの。対応する待機・切替・キャッシュ削除・記録維持は、本番ビルドを使うローカルのサブパス配信で自動検証済みです。
- 原書画像との教材照合。教材原本は未校正ドラフトで `ready_for_production:false`。98・99ページ未収録、125ページ本文なし、9図表の詳細不足。原本を推測で補正していない。
- 長期間のiOSによるストレージ保持、低メモリ端末での長時間学習。端末のブラウザデータ削除ではIndexedDBも消えるため、バックアップ機能を用意している。

実行環境のWebKit不足ライブラリはユーザー領域に配置して検証した。通常のCI環境は `npx playwright install --with-deps chromium webkit` で準備する。
