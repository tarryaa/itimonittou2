設定で「栞（オリジナル）」「アクア・ダーク」「アクア・ライト」の3テーマを選べます。元の配色を完全に戻せること、新テーマが描画数を増やさないこと、テーマ・文字サイズ・間違い履歴・深い位置を即時再起動後も維持すること、旧バックアップは元テーマになり、不正なテーマを拒否することを検証しました。起動時の配色ヒントは小さなlocalStorage値ですが、選択の原本は従来どおりIndexedDBです。

公開サイトでもChromium/WebKitで3テーマを切替→再読み込みし、選択・間違い記録の保持、赤字の透明マスク、横はみ出しなし、描画40問以下、メタカラー切替を確認しました。v1.3.0でも再検証し、[実測JSON](LIVE_READING.json)、[ダーク](theme-aqua-dark.png)、[ライト](theme-aqua-light.png)、[設定画面](theme-picker.png)を更新しています。公開サイトの基本検証では両エンジンとも6問だけを描画し、全1,496問は利用可能です。

## 絞り込み・全幅表示・インライン解答 v1.3.0

- 「★2以上」は★2・★3を対象にし、枝問では親の重要度を継承します。「★1以上」と従来の完全一致も選べます。教材原本では「★2のみ」393問、「★2以上」1,324問です。編集した重要度、他条件との組み合わせ、設定の再起動・バックアップ復元を検証しました。
- 全3テーマで問題の背景を画面左右端まで広げ、問題ごとの角丸・影・外側の余白を除去。320/390/430/1024pxで左右位置、本文余白、白背景（クラシック・ライト）、暗色背景、横はみ出しなしを確認しました。大画面では740pxを上限に中央配置します。
- 空欄は `fill_text` を同じ場所へ表示します。解答全文 `text` は「…」→「解答一覧（全文）」で確認でき、教材原本と編集データを維持します。開閉前後の空欄の位置・寸法と問題の高さが一致することを検証しました。
- マスクの収縮、文字の段階的な立ち上がり、短い光をopacity/transformで描画します。文字分割は36文字まで、長文は1つの連続した文字列にし、一括表示・prefers-reduced-motionではアニメーションを省きます。再タップによる途中反転、長文の折り返し、空のfill_textから全文へのフォールバックを確認しました。
- 吹き出しのDOM・画面内配置処理・スクロールリスナー・終了タイマーは削除しました。仮想スクロール、遠距離自動非表示、全表示、履歴、編集、バックアップ、更新・オフライン・深い位置からの再開を含め、上記43件のブラウザテストが成功しています。

## 未検証・元データの制限

- iPhone実機Safari、実機ホーム画面追加・アイコン起動、実機完全終了後の再起動。Playwright WebKitは実機Safariそのものではない。
- 公開サイトの旧版を保持した同一ブラウザで、更新通知から新版へ切り替える操作そのもの。対応する待機・切替・キャッシュ削除・記録維持は、本番ビルドを使うローカルのサブパス配信で自動検証済みです。
- 原書画像との教材照合。教材原本は未校正ドラフトで `ready_for_production:false`。98・99ページ未収録、125ページ本文なし、9図表の詳細不足。原本を推測で補正していない。
- 長期間のiOSによるストレージ保持、低メモリ端末での長時間学習。端末のブラウザデータ削除ではIndexedDBも消えるため、バックアップ機能を用意している。

実行環境のWebKit不足ライブラリはユーザー領域に配置して検証した。通常のCI環境は `npx playwright install --with-deps chromium webkit` で準備する。
