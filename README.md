# 日本史の栞 — 一問一答PWA

提供JSONから新規開発した、iPhoneを優先する日本史学習アプリです。React / TypeScript / Vite / IndexedDBで動作し、サーバーに学習記録を送信しません。

リポジトリ: https://github.com/tarryaa/itimonittou2

Pages公開URL（デプロイ成功後）: https://tarryaa.github.io/itimonittou2/

## 使い方

- 赤字はタップで個別に表示・非表示。空欄を押すと対応する印刷解答を上に表示します。
- 下の「すべて表示」で一括表示、「すべて隠す」で通常学習に戻ります。通常時は問題が画面から十分離れると個別表示をリセットします。
- 各問題の＋／−で日時付きの間違い記録を追加・取り消し。回数を押すと履歴と日時編集が開きます。
- 「！」は回数と独立した注意マーク。「…」から教材編集とタグ登録ができます。
- 絞り込みは期間・回数・重要度・時代・章・節・注意マーク・タグ・検索を組み合わせられます。
- 設定から文字サイズ、JSONバックアップ、復元、教材追加、教材の要確認事項を操作できます。

iPhone: Safariで公開URLを開く → 共有 → **ホーム画面に追加** → **追加**。初回はオンラインで教材の表示とキャッシュ完了を待ってください。実機iPhoneでの検証状況は後述の検証記録を参照してください。

## 教材について

[教材解析報告](docs/DATA_AUDIT.md) に件数・不足・順序・書式の扱いを記載しています。

- 144ページ、1,496問（親896＋枝600）、空欄・解答2,092件、図表25件。
- 98・99ページは未収録、125ページの本文なし。9図表は詳細不足。
- **教材原本自体が `ready_for_production:false` の未校正ドラフトです。** 原画像がないため原書との一致は未検証です。教材内の要確認事項158件をアプリに表示します。
- `public/data/original.json` は添付ファイルのバイト単位のコピーです。本文・解答は固有IDで結合し、全文 `text` と空欄補完用 `fill_text` を区別します。

## 保存・データ保護

IndexedDB v2の `originals` / `edits` / `learning` / `preferences` / `snapshots` に教材原本・編集・学習記録・設定・復元前退避を分離して保存します。問題IDと相対位置で閲覧を再開し、個別の赤字・解答表示は再起動時に隠します。

バックアップは教材とユーザーデータを含むJSONです。復元前に構造・全参照・編集・日時・設定を検証し、プレビューを確認してから置換します。直前の復元は取り消せます。教材再取り込みでは既存IDの競合を報告し、既存レコードと履歴・編集を保持します。追加的なDBマイグレーションを使い、Service Workerのキャッシュ更新ではDBを削除しません。

データは端末・ブラウザ・サイトのURLごとに保存されます。ブラウザのサイトデータを消すと記録も消えるので、定期的にJSONバックアップを端末外にも保管してください。複数端末間の自動同期はありません。

## 開発

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

[公開設定とPWA更新の説明](docs/DEPLOY.md)

`npm run build` は型検査・本番ビルド・キャッシュ生成を実行します。全配信ファイルのハッシュでキャッシュ世代を管理し、更新は学習状態の保存後にユーザーが適用します。相対URLなのでGitHub Pagesの任意のサブパスに対応します。
